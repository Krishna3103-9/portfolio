02 Approach

Design is how it behaves when the data is messy.

I care about the unglamorous parts: empty states, permissions, error copy, the third step of a flow. That’s where trust is actually built.

  1. 01

    Frame the real job

    Requirements, interviews, and a hard look at what people are trying to finish. I write the problem in one sentence and define success before opening a design tool.

  2. 02

    Map before pixels

    User flows, edge states, a data inventory. I find the step where doubt appears — missing information, a blocked action, an irreversible click — and design from there outward.

  3. 03

    Prototype in the browser

    React/Next.js, not static screens. I use AI agents to explore variants and scaffold, then edit by hand. If a state is hard to build, it’s usually hard to use.

  4. 04

    Ship, watch, revise

    Test cases, code review, feedback in the flow. I document decisions so the rationale survives the next iteration — and teammates can argue with the thinking, not the pixels.

✳ Gen-AI, in its place

I use agents for research synthesis, variant generation, scaffolding and first-draft microcopy — then edit hard and test. The flow, hierarchy and final words are judgement calls, not completions.
